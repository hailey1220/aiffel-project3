# lesson.json 형식

빌드 스크립트(`scripts/build_lesson.py`)가 읽는 파일. 값의 HTML은 `core`, `goals[].text`, `map.layers[].desc`, `closing`, `sections[].html`, 문제의 `q`·`o`·`e`·`hint`에만 쓸 수 있다.

```json
{
  "course": "바이브 코딩으로 웹 서비스 개발하기",          // 과정명 (상단 고정)
  "module": "AI 에이전트 도구 - 내 AI를 더 강하게 (…)",   // 모듈명 (상단 고정, 굵게)
  "title": "AI 에이전트 도구",                           // 첫 표지 큰 제목
  "subtitle": "내 AI를 더 강하게 (MCP·스킬·하네스)",       // 첫 표지 부제
  "topic": "AI 에이전트 도구: 범용 AI를 …로 만드는 법",     // 학습 주제 (주제: 부제)
  "core": "핵심 한 문장(강조 인용, 22px)",
  "core_tail": "보충 한 줄 (선택)",
  "goals": [ { "verb": "설명한다", "text": "…할 수 있다" } ],   // 4개
  "map": {
    "title": "큰 그림 제목",
    "layers": [ { "name": "모델", "desc": "…" } ],             // 3개 (가운데가 파란 칸)
    "steps_label": "순서 설명 (선택)",
    "steps": [ { "name": "하네스 고르기", "desc": "…" } ]       // 3~5개 (선택)
  },
  "deadline": "과제 마감은 2026년 11월 9일(월) 23:59예요.",    // 마지막 표지 (선택)
  "closing": "마지막 표지의 한 줄",
  "parts": [
    {
      "short": "에이전트",            // 왼쪽 학습 흐름에 보일 짧은 이름 (2~6자)
      "title": "에이전트란 무엇인가",
      "desc": "파트 표지 설명 1~2문장",
      "sections": [ { "title": "섹션 제목", "html": "<p class=\"lead\">…</p>…" } ],
      "quiz": [
        {
          "q": "문제",
          "o": ["정답", "오답", "오답", "오답"],   // 정답을 항상 첫 번째에! (화면에서 섞임)
          "e": "해설",
          "hint": "정답을 말하지 않는 실마리",
          "ref": 3                                   // 관련 섹션 번호 (이 파트의 sections 1부터)
        }
      ]
    }
  ]
}
```

## 분량 기준
- 파트: 4~8개. 한 파트에 섹션 4~10개
- 섹션 하나는 화면 1~2개 분량. 길면 나눈다
- 첫 섹션 제목은 보통 "들어가며"
- 섹션 id는 자동으로 `part{n}-{k}`가 된다 (예: 파트 2의 3번째 섹션 → `part2-3`)
