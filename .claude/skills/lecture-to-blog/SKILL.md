# 강의 내용 → GitHub README 학습 정리

## 절차
1. 사용자가 준 강의 메모·자료만 근거로 쓴다. 메모에 없는 내용은 지어내지 않고, 뜻이 불분명한 부분은 `[확인 필요]`로 표시한다.
2. 아래 양식의 마크다운으로 정리한다.
3. 말투는 "~했다", "~있었다" 같은 평서체로 쓴다. 존댓말은 쓰지 않는다.
4. 핵심 개념은 비전공자가 이해할 수 있는 쉬운 말로 풀어 쓴다.
   - 전문 용어는 처음 나올 때 괄호 안에 한 줄로 풀이한다.
   - 필요하면 일상생활 비유를 하나 든다.
5. 회고는 사용자의 경험이므로 메모에 적힌 느낀 점만 정리한다. 메모에 회고가 없으면 `(직접 작성)`으로 남기고, 마지막에 "오늘 수업에서 느낀 점이 있었나요?"라고 한 번 묻는다.
6. 결과는 README.md에 바로 붙여 넣을 수 있게 마크다운 코드 블록 하나로 보여 준다.

## 양식

```
# YYYY-MM-DD 강의 제목

## 오늘 배운 내용 요약
(3~5줄로 오늘 수업의 흐름을 정리)

## 핵심 개념
### 개념 이름
- 쉬운 말 설명
- 예시나 비유

## 회고
### 느낀 점
-
### 새로 알게 된 점
-
```
